# Data Entry & Excel Management

## Project Overview

This project demonstrates practical data entry, Excel organization, data validation, filtering, and administrative record management skills.

## Skills Demonstrated

- Accurate data entry
- Data organization
- Excel table creation
- Data validation
- Sorting and filtering
- Conditional formatting
- Basic Excel formulas
- Administrative record tracking
- Data quality control

## Main Deliverable

**Data Entry Tracker**

The final Excel workbook will contain structured records including:

- Record ID
- Date
- Client / Organization
- Category
- Description
- Amount
- Status
- Assigned To

## Tools

- Microsoft Excel
- Microsoft Word
- GitHub

## Portfolio Objective

The objective is to demonstrate the ability to transform raw administrative information into an organized, searchable, and professional Excel tracking system.
